# Vaccination Management System

A Vaccination Management System developed using Python and SQL for managing vaccination records efficiently.

## Features
- Add and manage vaccination records
- Store patient information
- Database integration using SQL
- Simple and user-friendly interface
- Record management operations

## Technologies Used
- Python
- SQL Server
- SQL Server Management Studio (SSMS)

## Project Files
- main.py – Main Python program
- vaccination_system.sql – Database script file

## Purpose
This project was developed for academic learning purposes to understand database integration with Python and record management systems.
